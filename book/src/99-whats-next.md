If you've worked through this book, look at what you can do now. You can explain how a request crosses the internet. You can write strict TypeScript, handle files, streams and async code, and build an HTTP server with nothing but Node. You can design a clean REST API, validate everything, handle every error consistently, and structure a project the way real teams do. And you have four projects on GitHub to prove it.

## Before you start Book 2

<ul class="checklist">
<li>Slotify v0.1 passes every row of the acceptance scenario.</li>
<li>Its README is complete, including known limitations and design decisions.</li>
<li>The repository is public and pinned on your GitHub profile.</li>
<li>You've written at least one LinkedIn post about what you built.</li>
<li>You can answer "What happens when you type a URL?" out loud, without notes.</li>
<li>You've started a habit of 2–3 easy coding problems a week (arrays, strings, hash maps) to warm up for interviews.</li>
</ul>

## Book 2: Data and Security (Phases 4–5)

- **SQL from scratch:** `SELECT`, `JOIN`, `GROUP BY`, subqueries, written by hand before any library.
- **PostgreSQL:** modelling Slotify's data properly, with constraints, indexes and `EXPLAIN`.
- **Transactions:** what really happens when two customers book the same slot at the same millisecond, and how the database stops it.
- **Time zones done right:** local opening hours, daylight saving time, `timestamptz`.
- **Authentication and authorization:** password hashing, sessions and tokens, and roles for owners, staff and customers.
- **Security:** the OWASP Top 10, rate limiting, CORS and secrets management.

**Slotify v0.2–v0.3** moves to PostgreSQL. Thanks to your layers, you'll mostly change the repositories, and that's the moment you'll see why Chapter 17 mattered.

## When you're stuck

Come back to the chat with the help template from Appendix E (or Chapter 3), or just say which task you're on and paste what you've got. Being stuck isn't a sign that you're bad at this. It's what learning feels like.

Good luck. Keep going.
